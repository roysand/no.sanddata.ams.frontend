# Quickstart: A High Demand Switch on the Heater Tab

## Automated

```bash
npm test && npm run lint && npm run build
```

## By hand (Roy, Admin, Hjemme)

1. Heater tab: the "High Demand" switch under the status line, off.
2. Turn it on: "Switching…", then "High Demand until tomorrow …" and the badge; the set point rises within minutes.
3. Turn it off: the badge goes; the set point returns.
4. As a viewer (or another account without Admin): no switch; the mode still shows when on.
5. 375 px, light and dark.
