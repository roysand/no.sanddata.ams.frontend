# Quickstart: A Usage Chart for the Car, on the Car Tab

## Automated

```bash
npm test && npm run lint && npm run build
```

## By hand (Hjemme, against production)

1. Car tab: "Car usage" below "Charging"; no session list (US2).
2. Day: today's total so far equals "Today" (SC-001); charging hours raised; yesterday dashed.
3. Month: the total equals "This month"; bars side by side with last month.
4. Tap a bar: its kWh and the previous period's. Step back with the arrow.
5. Choose Month on the Car tab, then open Now: Now's chart keeps its own period (FR-005).
6. 375 px, light and dark (SC-003).
